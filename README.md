# 🎯 Central de Estudos — Backend do Zero ao Arquiteto

## 🪜 A regra de ouro dos níveis

Cada nível tem um `00_guia_do_nivel.md` (escopo mínimo, estimativa, sinal de aprovação) e um `PROGRESSO.md` (seu estado atual). **Olhe só para o nível atual** — o resto do repositório existe para você não se perder, não para ser feito de uma vez.

```
JÚNIOR ──► PLENO ──► SÊNIOR ──► ARQUITETO
   └── trilha de EDA e normas acompanham todos os níveis
```

## 🚀 Início rápido

1. Leia o [METODO.md](METODO.md)
2. Abra [01_junior/00_guia_do_nivel.md](01_junior/00_guia_do_nivel.md) e faça a **primeira passada de marcação** (classificar, não estudar)
3. Registre em [01_junior/PROGRESSO.md](01_junior/PROGRESSO.md)
4. Estude na ordem dos arquivos; pratique na [trilha de EDA](02_estruturas_e_algoritmos/00_guia_da_trilha.md) em paralelo
5. Feche o nível com o [projeto-âncora](07_projetos/) correspondente
